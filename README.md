# Kontor Office

Downloads für **Kontor Office** – Textverarbeitung (Feder), Tabellenkalkulation (Raster) und Präsentationen (Bühne) für Windows.

## Installieren

1. Unter [Releases](../../releases/latest) die Datei `KontorSetup-<Version>.exe` herunterladen.
2. Starten und dem Assistenten folgen. Administratorrechte sind nicht nötig.

Windows zeigt beim ersten Start vielleicht „Der Computer wurde geschützt“, weil Kontor noch nicht signiert ist. Dann „Weitere Informationen“ → „Trotzdem ausführen“ wählen.

Updates findet Kontor selbst (Datei → Über Kontor).

Dieses Repository enthält nur die fertigen Installer, keinen Quelltext.
